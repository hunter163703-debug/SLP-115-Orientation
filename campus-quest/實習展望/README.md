# 臺灣語言治療臨床實習地圖 🗺️
Taiwan Speech-Language Pathology Clinical Internship Interactive Map

互動式單頁網頁應用程式（SPA），彙整全臺灣 **51 個語言治療臨床實習站**：26 家提供單位特色、優缺點、實習心得（**114 學年度實習座談會語言組**資料），另有 **25 家 115 學年度新增實習站**（僅標示「115 新增」站名），並附已完成去識別化處理的環境照片導覽與精選實習成果影片發表。

---

## 🌟 核心特色
1. **臺灣向量地圖互動導覽**：採用精美插畫地圖與動態脈衝標籤點，點選特定縣市即刻列出該區實習單位。
2. **兩階式直覺操作**：
   - 📍 點選縣市標籤點（臺北 10、新北 6、桃園 3、新竹 2、苗栗 1、臺中 12、彰化 3、南投 5、雲林 2、臺南 1、高雄 6）。
   - 🏥 點選醫院名稱進入詳情視窗，瀏覽環境照片相簿與條列式特色優缺點；115 新增站以金色標示「115 新增」。
3. **去識別化安全原則**：全數照片與文字內容皆已進行嚴格遮蔽與姓名去識別化處理。
4. **實習成果影片專區**：右下角懸浮按鈕一鍵開啟劇院級 YouTube 成果影片展示視窗。

---

## 📂 專案結構
- `index.html`：網頁主入口
- `styles.css`：Glassmorphism 玻璃帷幕設計系統與響應式排版
- `app.js`：地圖點擊、彈窗切換、照片輪播與影音播放控制
- `data.js`：51 筆實習單位結構化資料庫（26 筆 114 學年度特色 ＋ 25 筆 115 學年度新增站，後者 `isNew: true`）
- `台灣地圖2.png`：地圖底圖
- `實習單位整理/`：各實習單位去識別化環境照片與特色文字檔
  - 無環境照片的單位，詳情視窗會自動切換至「特色與優缺點」分頁。
