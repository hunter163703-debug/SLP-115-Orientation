# 臺灣語言治療臨床實習地圖 🗺️
Taiwan Speech-Language Pathology Clinical Internship Interactive Map

互動式單頁網頁應用程式（SPA），彙整全臺灣 **26 家語言治療臨床實習醫院/機構** 之單位特色、優缺點、實習心得，以及已完成去識別化處理的環境照片導覽與精選實習成果影片發表。

---

## 🌟 核心特色
1. **臺灣向量地圖互動導覽**：採用精美插畫地圖與動態脈衝標籤點，點選特定縣市即刻列出該區實習單位。
2. **兩階式直覺操作**：
   - 📍 點選縣市標籤點（臺北、新北、桃園、新竹、苗栗、臺中、彰化、嘉義、高雄、宜蘭）。
   - 🏥 點選醫院名稱進入詳情視窗，瀏覽環境照片相簿與條列式特色優缺點。
3. **去識別化安全原則**：全數照片與文字內容皆已進行嚴格遮蔽與姓名去識別化處理。
4. **實習成果影片專區**：右下角懸浮按鈕一鍵開啟劇院級 YouTube 成果影片展示視窗。

---

## 📂 專案結構
- `index.html`：網頁主入口
- `styles.css`：Glassmorphism 玻璃帷幕設計系統與響應式排版
- `app.js`：地圖點擊、彈窗切換、照片輪播與影音播放控制
- `data.js`：26 家實習單位結構化資料庫
- `台灣地圖2.png`：地圖底圖
- `實習單位整理/`：各實習單位去識別化環境照片與特色文字檔
