# 聽語星航記 - 互動式新生闖關地圖網頁

本專案是專為亞大聽語系 115 新生設計的互動式闖關網頁。新生（或由老師投影操作）可以控制「聽語小熊」角色，在亞洲大學的 10 大校園地標間進行探索與問答。

---

## 🛠️ 開發日誌 (收工記錄)

### 1. 已完成事項
* **首頁與地圖架構**：完成封面跳轉、地圖節點與小熊 Avatar 的排版，採用「聽語10問闖關封面」作為主地圖背景。
* **精準座標定位**：對齊 01～10 數字圓圈位置，解決不同解析度下小熊與地標位置偏移的問題。
* **關卡問答功能**：匯入 `亞大聽語系-新生課程10 問.md` 的文字內容，拆分 A/B 選項獨立解析，並新增「回上一步」按鈕供教學檢討使用。
* **地圖按鈕客製化**：
  * Q1（太極湖）對接 **「課程地圖」**。
  * Q3（護理學院）對接 **「課程解析地圖」**。
  * Q6（管理暨社會科學學院）對接 **「證照地圖」**。
  * Q10（亞大醫院）對接 **「職涯地圖」**。
* **版權說明**：在左下方固定新增透明圓角設計的「© 亞洲大學 聽力暨語言治療系 林樺鋒老師製作」聲明。
* **部署上線**：專案已推送到 GitHub (`SLP-115-Orientation`)，並成功啟用 GitHub Pages。

### 2. 踩坑與心得
* **背景覆蓋裁切問題**：`background-size: cover` 會因為視窗比例不同而裁切圖片，導致百分比座標點位移。改為固定 `aspect-ratio` 容器搭配 `background-size: 100% 100%` 後，徹底解決了點位偏差。
* **選項多重解說需求**：在教學情境中，老師需要對 A 和 B 選項都進行檢討，原本的單向點擊流程無法回頭。新增「回上一步」狀態控制後，即可重複展示雙向解析。

### 3. 下一步計畫
* 讓大一新生於定向輔導活動中實際操作，點擊每個關卡學習學分架構、證照資訊與職涯規劃。
